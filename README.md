My First Website

About the Project

This is my first website, created as part of my first milestone. It is a simple personal webpage where I introduce myself and share what I am learning.

Technologies Used

- HTML – To create the webpage structure.
- CSS – To style the webpage.
- JavaScript – To add dark mode functionality.

Features

- Simple personal introduction.
- Clean and basic design.
- Dark mode toggle button.

How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open "index.html" in a browser.
4. Click the button to switch to dark mode.

What I Learned

I learned how HTML, CSS, and JavaScript work together to create a simple website.
